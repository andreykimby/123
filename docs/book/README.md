# Брошюра «Skarynagram — руководство»

- `book-print.pdf` — **для печати**: 2 листа A4, на каждом по две страницы A5.
- `book.pdf` — та же книга постранично (A5), для чтения с экрана.

## Печать (без настроек)

1. Открыть `book-print.pdf`, печать **на двух сторонах листа**, масштаб **100 % / «Реальный размер»**
   (не «По размеру страницы»), переплёт по **длинному краю** (это значение по умолчанию).
2. Сложить стопку листов пополам, как книгу, — страницы идут по порядку.

На экране страницы в `book-print.pdf` выглядят повёрнутыми — так и должно быть:
благодаря этому принтеру не нужно выбирать ориентацию и «переплёт по короткому краю».

## Пересборка

```bash
python3 docs/book/build.py
```

Нужны `pandoc`, Chromium и `pypdf`. Текст — в `book.md`, оформление — в `book.css`.
